🌦️ Responsive Weather Dashboard

A sleek, modern weather application that fetches real-time data from a public API. This project demonstrates how to handle asynchronous JavaScript, interact with RESTful APIs, and create a glassmorphism-inspired responsive UI.

✨ Features

Real-time Search: Get weather data for any city in the world.
Dual-API Integration: Uses geocoding to translate city names into coordinates, then fetches precise weather data.
Glassmorphism UI: A modern, semi-transparent design that adapts to any screen size (mobile, tablet, desktop).
Keyboard Support: Press "Enter" to search instantly.
Error Handling: Gracefully handles invalid city names or network issues.
